## 概述

设计一个具有科技感和炫酷视觉效果的登录页面，支持多种登录方式（邮箱密码、手机验证码、微信），适用于传统 Web 应用（桌面优先，兼容移动端）。

---

## 配色方案

| 用途 | 颜色值 | 描述 |
|------|--------|------|
| 主背景渐变 | `#0a0e27` → `#1a1f3a` | 深邃星空感，缓慢流动 |
| 主强调色 | `#00f0ff` | 青色霓虹，用于按钮、高亮 |
| 次强调色 | `#7b2dff` | 紫色霓虹，用于渐变、点缀 |
| 成功色 | `#00ffa3` | 荧光绿，成功状态 |
| 主要文字 | `#ffffff` | 白色 |
| 次要文字 | `#a0aec0` | 灰色 |
| 卡片背景 | `rgba(255, 255, 255, 0.05)` | 半透明 + 玻璃态模糊 |
| 边框 | `rgba(0, 240, 255, 0.3)` | 青色半透明 |

## 页面布局

### 桌面版 (>1024px)
- 左侧：展示区（45% 宽度）
  - Logo / Slogan
  - 视频/截图轮播
  - 客户案例滚动展示
- 右侧：登录卡片（55% 宽度）
  - 登录表单
  - 社交登录

### 平板版 (768-1024px)
- 上下分栏布局
- 上部：精简展示区（30% 高度）
- 下部：登录表单（70% 高度）

### 手机版 (<768px)
- 单列布局
- 展示区隐藏或保留精简版头部

## 核心功能

### 1. 登录方式
- **邮箱登录**: 邮箱 + 密码
- **手机验证码登录**: 手机号 + 验证码
- **微信登录**: OAuth 授权

### 2. 表单元素
- Tab 切换（邮箱登录 / 手机验证码）
- 输入框（带聚焦动效）
- "记住我" 复选框
- "忘记密码" 链接
- 登录按钮（渐变发光效果）
- 微信登录按钮
- 注册账号链接

### 3. 展示区内容
- 产品 Logo
- Slogan: "未来已至，即刻登录"
- 视频/截图轮播（3-5 张）
- 客户案例/评价（滚动展示）

## 视觉效果

### 背景效果
- **粒子网格动画**: Canvas 绘制浮动粒子，粒子间带连接线
- **流光渐变**: 背景色缓慢流动
- **玻璃态卡片**: `backdrop-filter: blur(20px)`

### 交互动效
- **输入框聚焦**: 霓虹色边框发光动画
- **按钮悬停**: 渐变色流动 + 阴影扩散
- **Tab 切换**: 滑动下划线过渡
- **页面加载**: 元素依次淡入上浮（staggered animation）

---

## 技术栈

- **HTML5**: 语义化标签
- **CSS3**: Flexbox/Grid、动画、玻璃态效果
- **原生 JavaScript**: 无框架依赖
- **Canvas API**: 粒子背景动画

## 表单验证规则

### 邮箱登录
- 邮箱：标准邮箱格式
- 密码：最少 8 位，包含字母和数字

### 手机验证码登录
- 手机号：11 位手机号格式
- 验证码：6 位数字
